# Academic Scheduling Engine

A flexible academic routine generator built using Python and Google OR-Tools CP-SAT.

## Features

- Generic university scheduling engine
- Supports theory, lab, tutorial, seminar, workshop
- Multiple programs and departments
- Configurable teaching assignments
- Weekly and alternate-week sessions
- Parallel lab groups
- Multiple instructors per activity
- Room allocation
- Teacher preferences
- Hard and soft constraints
- Extensible architecture
